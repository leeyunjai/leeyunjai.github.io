샤오미가 9월 7일 중국에서 첫 와이드 폴더블 스마트폰 **샤오미 18 폴드**를 공식 발표했습니다.
자체 설계 칩과 라이카 카메라, 6000mAh 배터리를 앞세워 갤럭시 Z 폴드 시리즈가 오래 지켜온
빅 폴더블 시장에 정면으로 도전장을 냈습니다.

## 샤오미 18 폴드

| 항목 | 내용 |
|---|---|
| 외부 화면 | 5.38형 AMOLED, 1712×1168, 120Hz |
| 내부 화면 | 7.58형 플렉시블 AMOLED, 2364×1672, 120Hz |
| 칩셋 | Xring O3 (샤오미 자체 설계, 10코어 CPU / 16코어 GPU) |
| 메모리 | 최대 16GB, 1TB 모델은 LPDDR6 지원 |
| 카메라 | 라이카 튜닝, 200MP 메인 + 50MP 초광각 + 50MP 페리스코프 망원 |
| 배터리 | 6000mAh |
| 두께 | 펼쳤을 때 5.02mm / 접었을 때 10.68mm |
| 무게 | 219g |
| 가격(중국) | 16GB+512GB 12,999위안, 16GB+1TB 14,999위안, 세라믹 16GB+1TB 15,999위안 |
| 판매 시작 | 9월 10일(중국) |

기본 모델 가격은 12,999위안부터 시작합니다. 국내외 정발 여부는 아직 확인되지 않았습니다.

## 경쟁 제품 비교: 갤럭시 Z 폴드7

| 항목 | 샤오미 18 폴드 | 갤럭시 Z 폴드7 |
|---|---|---|
| 외부 화면 | 5.38형, 120Hz | 6.5형 FHD+, 120Hz |
| 내부 화면 | 7.58형, 120Hz | 8.0형 QXGA+, 120Hz |
| 칩셋 | Xring O3 (자체 설계) | 스냅드래곤 8 엘리트 포 갤럭시 |
| 배터리 | 6000mAh | 4400mAh |
| 카메라(메인) | 200MP + 50MP 초광각 + 50MP 망원 | 200MP + 12MP 초광각 + 10MP 망원 |
| 두께(펼침) | 5.02mm | 확인 필요 |
| 무게 | 219g | 확인 필요 |
| 시작가 | 12,999위안(중국) | 1,999달러(미국) |

![샤오미 18 폴드와 갤럭시 Z 폴드7 비교: 배터리 6000 대 4400mAh, 내부 화면 7.58 대 8.0인치, 외부 화면 5.38 대 6.5인치, 초광각 50 대 12MP, 망원 50 대 10MP](/images/posts/phone-xiaomi-18-fold.ko-compare.png "위 표를 막대로 그린 것입니다. 배터리와 보조 카메라는 샤오미가, 화면 크기는 갤럭시가 앞섭니다.")

숫자만 보면 샤오미 18 폴드가 배터리 용량과 카메라 화소에서 앞섭니다. 다만 갤럭시 Z 폴드7은
이미 여러 국가에서 정식 판매 중이고 삼성 특유의 방수·방진 인증과 사후지원 체계를 갖춘 반면,
샤오미 18 폴드는 이번 발표가 중국 내수용이라 글로벌 유통망과 애프터서비스 검증이 아직 없습니다.

## 장단점

**장점**
- 4400mAh에 머물러 있던 빅 폴더블 배터리 용량을 6000mAh로 크게 늘렸습니다.
- 5.02mm(펼침) 두께로 동급 대비 얇은 편에 속합니다.
- 라이카 3안 카메라로 접히는 폰치고는 사진 스펙이 준수합니다.

**단점**
- 글로벌·국내 출시 계획이 아직 확인되지 않아 실제 구매 가능성이 불확실합니다.
- 방수 등급, 힌지 내구성 인증 정보가 발표 자료에 없어 확인이 필요합니다.
- 자체 칩 Xring O3의 실사용 성능·발열은 아직 벤치마크로 검증되지 않았습니다.

**어떤 사용자에게 맞나**: 중국 내에서 큰 배터리와 얇은 두께의 폴더블을 원하는 사용자에게는
매력적인 선택지입니다. 반면 국내에서 정식 A/S와 방수·내구성 보증이 중요한 사용자라면 아직은
갤럭시 Z 폴드7 쪽이 안전한 선택입니다.

## 국내 출시 여부

샤오미 18 폴드의 국내 출시 계획은 확인되지 않았습니다("확인 필요"). 샤오미는 폴더블 라인업을
그동안 주로 중국 내수 시장 중심으로 운영해 왔습니다.

## 총평

샤오미 18 폴드는 배터리 용량과 두께라는 폴더블의 오랜 약점 두 가지를 동시에 개선하며 등장했습니다.
스펙만 보면 갤럭시 Z 폴드7을 넘어서는 항목이 여럿이지만, 글로벌 유통과 내구성 검증이라는
숙제가 남아 있어 실제 구매 판단은 정식 출시 소식을 더 지켜본 뒤 내리는 편이 안전합니다.
